# Тестовое задание для стажировки в **LiptSoft**.  

## Подготовка

Установите OpenJDK 24.

## Сборка и запуск тестов

Для сборки проекта и запуска всех тестов используйте:

```bash
mvn clean install
```

## Запуск приложения

Нужно запустить Application.main

## Ручное взаимодействие с приложением

http://localhost:8080/swagger-ui
